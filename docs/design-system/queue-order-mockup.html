Queue order

Today the line is first come, first served, moved by hand with the arrows. This adds rules the owner can switch on (main branch first, shortest first, fair turns between projects, aging so nothing waits forever) and a priority per project. Every waiting row then says in a few words why it stands where it does. Moving by hand stays, and always wins.

An Order page

Order becomes a page of its own. The rules are a ladder, strongest first, that you can switch and re-rank; beside it the projects; under both, the line as these rules leave it, each row with its reason in a column.
