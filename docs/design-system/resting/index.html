A node that rests

Mockups of 2026-11-25 for M23.5, to pick from before anything is built. A node checks itself; while a check fails it rests and takes no job, or holds back only Docker or Xcode. Each problem comes with what is wrong, how to fix it and since when. The question here is where the dashboard says so, and how loudly: on the node, in the strip, or on request.

A

On the node

Fable suggests: its Machines page

A line under the node's name, and the node's sentence on each waiting job; both open in place to the fix and Check now.

  • Machines box one line more a node with a problem.
  • Machines page a second row, always open.
  • Waiting job the full reason, opening to the fix.
  • Above the panels nothing.
 B

In the strip

Fable suggests

One line a node in the strip above the panels, on every page, with the fix and Check now. Node and job carry an icon and a few words.

  • Machines box as today, with the state's icon.
  • Machines page the state, and withheld tags struck out.
  • Waiting job four words that lead to the strip.
  • Above the panels the problem, said once.
 C

On request

Fable suggests: its Health tab

A mark on the node and on the job opens a small panel; a Health tab in the node's settings lists every check and holds the least free space.

  • Machines box the state icon is a button.
  • Machines page a Health column.
  • Waiting job a mark beside its time.
  • Node settings a Health tab, with min_free.

What Fable suggests, part by part

The options differ in where the problem is said, so parts of them go together.

Telling the owner
BThe strip. A resting node runs nothing until someone acts, so it should be seen from every page, once, with its fix. It is where the low-space warning already is, which a rest for disk grows out of.
Machines box
BThe state icon only. The top row keeps its size with any number of nodes.
Machines page
AThe second row under the node. The page has the room, and with several nodes down it keeps each fix beside its node; the strip stays above it.
Waiting job
BFour words and the icon. The agent gets the full sentence in its terminal; the owner needs to know which node, and where the fix is.
Node settings
CThe Health tab, with any option: the passing checks and min_free have no other home.

The same in every option

Long before a rest, the disk warning: under 10% free (or 10 GB) the strip says so in amber, as the low-space warning does today. And the state icons: a bed for resting, in the danger colour; a triangle for one part down, in the warning colour; a capability held back stays named, struck out.
