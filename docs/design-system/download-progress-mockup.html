Download progress

Behind a slow VPN a job that restores a cache or installs packages sits at 0.0 cores for minutes and looks hung. The running card should say it is downloading, how far and how fast, and tell slow apart from stalled. Each option shows an agent's job (no total known) and a GitHub CI run (total known), in the running list as it is today.

  • Reads asCores at 0.0 with Down moving is a download; both at rest is a stall. No new shape to learn.
  • StallThe fill stops where it was and turns to the warning colour, with the warning icon and the seconds since the last byte.
  • CostsA card grows by two lines while it downloads, and a download with no total has a track that cannot fill.
