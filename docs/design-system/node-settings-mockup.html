Node settings

mulebox suggests how a node should run and has always just done it. Here the owner sees the suggestion and can overrule it: how many jobs at once, and whether the node is preferred, normal or a fallback. A change applies to the next job; a node on another machine takes it on its next check-in and reads "pending" until then.
