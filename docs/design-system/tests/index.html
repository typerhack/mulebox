The tests a job ran

Mockups of 2026-11-15 for M24.1, to pick from before anything is built. When an agent's job passes, mulebox counts the tests its runners ran. A pass with no tests, or with fewer than the last pass, becomes a failure with exit code 8, unless the agent let it through with a reason. The question here is how a finished job shows that count on its row and on its page.

A

The number alone

An icon and the count at the end of the row; the icon's shape and colour say how it stands, the sentence is a tooltip or a tap.

  • Row unchanged in height.
  • Why it failed in a tooltip, on request.
  • Job's page one clause and rows in Job details.
 B

A line when it matters

Fable suggests

The count as a quiet number; fewer tests, no tests and an allowed drop say so in words under the job's name, with the agent's reason.

  • Row one line taller, only for those three.
  • Why it failed in words on the row.
  • Job's page a strip with the way on, and a Tests panel by runner.
 C

The suite over time

"Fewer tests" and "No tests ran" as states of their own, and the last runs' counts as small bars on every row.

  • Row same height, with a small chart.
  • Why it failed in the state's own words.
  • Job's page a chart of the last 16 runs by runner.

Why B. The new failure is the one thing here an owner must not misread: a job that failed because tests went missing looks, in a list, exactly like a job with a broken test. Only B says which it is in words on the row, with the numbers and with no hover, so it reads the same on a phone; it reuses the line a failed GitHub job already has, and it is the only one that puts the agent's reason for a drop where the owner will see it. It also keeps quiet: a normal pass is one number. A is lighter but hides the reason behind a learned icon. C is the most telling for a suite's growth, but a drop of 8 in 3470 cannot be seen in bars from zero, and it costs a chart on every row; its chart could join B's Tests panel later.

Every option shows the same seven jobs: a normal pass, a pass with 12 more tests, a failure for 8 fewer, a failure for a runner that ran none, a pass allowed with fewer and its reason, a lint with no summary, and an ordinary failed command. Each page has the Jobs box, the job's page, the other situations and the History page at 390 px. The rest of the dashboard is as today. Static pages with example data; colours, type, space and corners come from tokens.css; the icons are Lucide, outline.
